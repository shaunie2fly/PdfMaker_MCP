# PdfMaker_MCP

PdfMaker_MCP is a simple tool that converts Markdown files into PDFs. It was
created to help generate documentation or study material that can easily be
shared with large language models (LLMs).

## Prerequisites

- [Node.js](https://nodejs.org/) and `npm` must be installed.

## Installation

Clone the repository and install its dependencies:

```bash
npm install
```

Build the project before running:

```bash
npm run build
```

## Example Usage

After building, use the tool by specifying a Markdown file:

```bash
node dist/index.js docs/example.md
```

This command will produce a PDF version of `docs/example.md` in the output
folder.

## Mermaid Diagrams

To include [Mermaid](https://mermaid.js.org/) diagrams in your Markdown, wrap
the diagram syntax in a code block labeled `mermaid`:

```mermaid
graph TD;
    A-->B;
```

The rendered PDF will contain the diagram generated by Mermaid.
